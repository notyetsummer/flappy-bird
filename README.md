# Pygame платформер + Flappy Bird

Сборник из двух игр на **Python + pygame**: платформер (с уровнями, редактором и
пиксель-арт ассетами) и улучшенный Flappy Bird. Запуск из корня проекта.

## Установка

```bash
python3 -m pip install -r requirements.txt
```

## Установка ассетов

Базовый набор пиксель-арт ассетов (CC0) генерируется скриптом:

```bash
python3 scripts/setup_assets.py
```

Ассеты складываются в `assets/`. Если их нет — игра не падает, а рисует
примитивы (fallback). Подробнее об источниках и о замене на наборы Kenney —
см. `assets/licenses/asset_sources.md`.

## Запуск игры

```bash
python3 main.py
```

Откроется меню выбора уровней. Выбор: **мышью** (наведение подсвечивает, клик —
запускает), стрелками/`WASD` + `Enter`, либо цифрами `1–9`.

Управление в игре работает на **любой раскладке** (в т.ч. русской): движение
читается по физическим клавишам (scancode), поэтому `WASD` = `ЦФЫВ`, а `Space` /
стрелки — прыжок, `G` / `Shift` — смена гравитации, `F` — взаимодействие.

## Запуск конкретного уровня

```bash
python3 main.py --level levels/level_001.json
```

## Запуск редактора

Из меню выбора уровней — пункт **«[ Открыть редактор уровней ]»** (или клавиша `E`).
Либо напрямую:

```bash
python3 main.py --editor
```

Созданные уровни сохраняются в `levels/*.json` и автоматически появляются в меню
выбора уровней (помечены `[JSON]`). Отдельный реестр не нужен — источник правды
это сама папка `levels/`; каждый файл хранит все объекты, координаты и параметры.

### Обмен картами между игроками

Уровень — это один самодостаточный `.json`-файл. Чтобы поделиться картой,
просто **передай файл** (мессенджер, почта, облако и т.п.). Получателю достаточно
положить его в папку `levels/` — уровень сразу появится в меню (`[JSON]`) и в
списке `Load` редактора. Никакой установки и регистрации не требуется.

> Совет: давай файлам осмысленные имена (`my_castle.json`), т.к. в меню
> показывается имя файла. Редактор по умолчанию сохраняет в `level_editor.json`
> (рабочий файл, не коммитится) — для шеринга переименуй/скопируй его.

В репозитории идут два готовых уровня: `levels/level_001.json` (демо) и
`levels/level_002.json` (вертикальный спуск с пилами — проверка падения и пил).

Редактор уровней (чистый pygame). Окно **растягивается** — тяни за край, чтобы
видеть уровни большой ширины/высоты. Мышью кликаются кнопки `Save`,
`Load v` (выпадающий список файлов `levels/*.json`), `Test`, список режимов
(`Режим: … v`), `Ластик`, `Undo`/`Redo`, `Выше +`/`Ниже +`, а также строки
палитры. Клавиши работают на любой раскладке (scancode).

- **Ластик** — кнопка-переключатель: при включённом ластике ЛКМ стирает
  (курсор красный). ПКМ стирает всегда.
- **Выше + / Ниже +** — наращивают уровень сверху/снизу (вверху всё содержимое
  сдвигается вниз). Любое изменение откатывается через **Undo** (`Ctrl+Z`) /
  **Redo** (`Ctrl+Y`).
- **Пилы** — выбери в палитре `obstacles → saw`. Появится панель «Пила»
  (размер, период=скорость, направление). Маршрут задаётся двумя кликами:
  старт → конец. Esc отменяет недорисованную пилу.

| Клавиша | Действие |
|---|---|
| `1`–`9`, `0` | режимы: tiles / platforms / enemies / items / obstacles / player start / level end / select / background / test |
| ЛКМ / ПКМ | поставить / удалить объект |
| клик по палитре / колесо мыши | выбрать ассет в текущей категории |
| `Ctrl+Z` / `Ctrl+Y` | отменить / повторить |
| `WASD` / стрелки | двигать камеру |
| `+` / `-` | зум, `[` / `]` — размер кисти |
| `.` / `,` | ширина уровня, `PgUp` / `PgDn` — высота |
| `G` / `H` | сетка / хитбоксы |
| `Ctrl+S` | сохранить (`levels/<имя>.json`) |
| `T` | playtest текущего уровня (выход назад — `Esc`) |
| `Esc` | закрыть список / отменить пилу / выйти из редактора |

```bash
python3 main.py --debug-hitboxes
```

## Flappy Bird (отдельный хаб-меню с двумя играми)

```bash
python3 "Export_Version_2 (2).py"
```

В имени файла есть пробелы и скобки — в командной строке берите его в кавычках.

## Структура

```text
main.py                 # точка входа (--editor / --level / --debug-hitboxes)
platformer.py           # движок и игровая логика (физика на pygame.Rect)
scripts/setup_assets.py # генерация ассетов + файлов лицензий
src/assets/             # asset_loader.py, asset_registry.py
src/levels/level_io.py  # JSON <-> LevelData
src/editor/level_editor.py
assets/                 # спрайты по категориям + licenses/
levels/                 # JSON-уровни (level_001.json — демо)
```

## Зависимости

См. `requirements.txt`: `pygame`, `pygame-menu`.
